# all-rivals (`/rivals/all`) — iPhone notes

> **What:** iPhone implementation state and decisions for the full rival list of one scope. **Read when:** changing this page on iPhone. Behavior: [spec.md](spec.md) (stub — this file is the source of truth for what's actually built until spec.md is promoted).

Source: `FortniteFestivalWeb/src/pages/rivals/AllRivalsPage.tsx`. Service: same `RivalsEndpoints.cs`/`LeaderboardRivalsEndpoints.cs` reads as [rivals/ios.md](../rivals/ios.md).

- Implemented: `AllRivalsScreen` (`Features/Rivals/AllRivalsScreen.swift`), reached via `AppRoute.allRivals(category:)`. The web's route takes independent `category`/`mode`/`rankBy` query parameters; native `AppRoute.allRivals` has a single `category: String` (an orchestrator-owned seam this lane cannot extend — see "Seam changes needed" in the final report), so `RivalAllCategory` (`FestivalCore/Rivals.swift`) packs the scope into one colon-separated token: `song:<instrument>` or `leaderboard:<instrument>:<rankBy>`. A bare instrument raw value with no prefix decodes as a song scope (back-compat for any future deep link). The screen loads the full (unlimited) rival list for that one scope into a single `FestivalGlassSection`, with loading/empty/error states and the same navigation-context stash as the hub before pushing `AppRoute.rivalDetail`.
- Simplified vs. web this pass: only single-instrument song/leaderboard scopes are supported (matching what `RivalsScreen`/`CompeteScreen` actually link to). The web's `common` (cross-instrument intersection) and settings-derived multi-instrument `combo` categories are not implemented — `RivalAllCategory.decode` returns `nil` for those tokens today, and the screen shows an "Unknown Category" empty state rather than guessing.
- Tests: `RivalsTests.swift` covers `RivalAllCategory` round-tripping (song scope, leaderboard scope, bare-instrument back-compat, malformed-token rejection). `tools/ios_sim.py drive --route "rivals"` plus a scripted tap into a "View All Rivals" row verified the push (2026-09-28).
