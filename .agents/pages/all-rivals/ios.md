# all-rivals (`/rivals/all`) — iPhone notes

> **What:** iPhone implementation state and decisions for the full rival list of one scope. **Read when:** changing this page on iPhone. Behavior: [spec.md](spec.md) (stub — this file is the source of truth for what's actually built until spec.md is promoted).

Source: `FortniteFestivalWeb/src/pages/rivals/AllRivalsPage.tsx`. Service: same `RivalsEndpoints.cs`/`LeaderboardRivalsEndpoints.cs` reads as [rivals/ios.md](../rivals/ios.md).

- Implemented: `AllRivalsScreen` (`Features/Rivals/AllRivalsScreen.swift`), reached via `AppRoute.allRivals(scope:)`. **Landed 2026-09-28:** the web's route takes independent `category`/`mode`/`rankBy` query parameters; native `AppRoute.allRivals` now carries the same information as one typed, `Hashable` `RivalScope` (`.song(instruments:)`, `.leaderboard(instrument:rankBy:)` or `.combo(token:instruments:)` — see [rivals/ios.md](../rivals/ios.md)) instead of the earlier packed-string `RivalAllCategory` workaround (removed; this lane had orchestrator permission to change the `AppRoute` case itself, so the string-packing seam is gone). A `.song` scope with exactly one instrument is a normal per-instrument list; two or more is "Common Rivals" (`RivalCommonRivals.intersect` over the full, not preview-capped, per-instrument lists). The screen loads the full (unlimited) rival list for its scope into a single `FestivalGlassSection`, with loading/empty/error states, before pushing `AppRoute.rivalDetail(scope:)` with the same scope.
- Simplified vs. web this pass: a `.combo` scope always names one server-computed list (matching what `RivalsScreen` actually links to); there's no independent settings-derived re-resolution at this route the way the web's `resolveRivalCombos` does.
- Tests: `RivalsTests.swift` covers `RivalScope.debugToken` round-tripping (used only by `DebugLaunchRoute`) and the new combo-endpoint URL/validation coverage. `tools/ios_sim.py drive --route rivals` plus a scripted tap into a "View All Rivals" row verified the push and the typed-scope title/list rendering live (2026-09-28, `Lead Rivals` full list for account `195e93ef108143b2975ee46662d4d0e1`).
