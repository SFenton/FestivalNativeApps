# Songs Filter — iPhone notes

> **What:** the SwiftUI Filter sheet as built, layout lessons and open work. **Read when:** changing Songs filtering on iPhone (Lane S). Spec: [spec.md](spec.md).

- Entry points: `apple/Sources/FestivalCore/{SongGeneralFilter,SongShopFilter,SongPlayerScoreFilter}.swift`, `apple/Sources/FestivalUI/Features/Songs/SongsFilterSheet.swift`. `SongShopFilter.filtered` preserves input order; `FestivalSession.shopOffersById` comes only from the validated feed; one `SongShopPublicationPolicy` decision gates Filter, Shop Sort/grouping and row badges.
- Toolbar Filter for every viewer while saved filters decode (issue #77); its tint and accessibility value name active General choices ("Year filter", "Duration filter", "Item Shop filter", "Double Bass filter") and score checks.
- **General (#77):** `SongGeneralFilter` (excluded decades / minute buckets, `SongShopFilter` available/unavailable, Double Bass pair) is one bounded JSON value under `fst.songs.generalFilters` (≤4096 bytes, decades 0–9990 step 10, durations 0–10, unique; else the corrupt-filter Reset screen). Legacy `fst.songs.filterInShop` / `.filterLeavingTomorrow` migrate once to Available only and are removed on save. The sheet lists General first as separate Form sections, each a `DisclosureGroup` (`fst.songs.filter.{year,duration,shop,double-bass}` on the label; options `.shop-available`/`.shop-unavailable`, `.double-bass.{supported,unsupported}`, `.<year|duration>.<key>`; the heading is `fst.songs.filter.general`, shared with Android/Windows) that opens only while restricted (HIG Disclosure controls: "Hide details until relevant"); Year/Duration Select All / Clear All sit in the section header like the per-instrument buckets. Options come from the loaded catalogue (`decades(in:)`, `durationBuckets(in:)`). Item Shop shows only while Shop is visible and notes "Item Shop filters need matching public Songs and Shop data." when one category is off without a matching feed. Player sections stay gated on `selectedPlayer`; Reset Filters clears everything. iOS uses switches in list rows (HIG Toggles "Use the switch style only in a list row"); macOS: [macos.md](macos.md).
- The single-chart Instrument picker (previously its own always-visible toolbar `Menu` on Songs) is now part of this sheet's draft: `draftInstrument`/`appliedInstrument`, applied with the Shop and score checks as each changes (no Cancel/Apply since operator 2026-09-28; Done closes), matching web's `FilterDraft.instrumentFilter`. Shown only when a player is selected (`selectedPlayer`), since Filter itself only reaches mobile users with player/Shop data.
- **Percentile and Stars (Lane A3):** with a selected player and one instrument chosen, two disclosure sections follow the score checks: Percentile (No Score, Top 1%…Top 100%) and Stars (gold, 5…1 star images, No Score), each with Select All / Clear All (`fst.songs.filter.{percentile,stars}[.select-all|.clear-all|.<key>]`). They are part of `SongPlayerScoreFilter` (`excludedStars`/`excludedPercentiles`, web `starsFilter`/`percentileFilter` `false` entries), so they share its bounded decoding (unknown or duplicate keys → the corrupt-filter Reset screen), its pause rules, and its clearing on player deselection. Buckets read the Songs instrument's score only (`SongStarsBucket`, `SongPercentileBucket`: first threshold ≥ `rank / totalEntries × 100`, 0 for no score or no rank) and apply only while Songs shows one visible instrument; without one the saved choice is kept but inert, like the web. Older saved filters (no bucket keys) decode unchanged and filters without buckets encode to the same bytes.
- Sheet: opaque full-height system sheet; General sections + Instrument section (when a player is selected) + "Player Score and FC Filters" disclosure (expanded when a saved predicate exists); the shared `FestivalModal`'s system Close top-right (`fst.songs.filter.done` kept); Reset inside the Form (now also clears the instrument choice).
- Put the chart ID on the disclosure **label**, not the whole `DisclosureGroup` (iOS 26 replaced all nested toggle IDs). The iOS title and Form are separate vertical siblings so AX5 text scrolls in a clipped viewport, not behind Liquid Glass.
- At AX5, scroll the **Form itself** until Reset is fully above the footer.
