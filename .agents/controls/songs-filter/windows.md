# Songs Filter — Windows notes

> **What:** the Windows Filter flyout, its draft model and persistence. **Read when:** changing `SongFilterDraft`, the flyout in `SongsPage.xaml`, `SongFilter` / `SongPlayerScoreFilter` or the settings migration. Rules: [spec.md](spec.md).

- Light-dismiss `Flyout` sized like the web's 440 epx desktop drawer (clamped to the window; its height fits the space below the button so the red **Reset** footer stays on screen). Order follows the web `FilterModal`:
  1. **General** heading (`fst.songs.filter.general`), available with or without a selected player: **Year** and **Duration** `Expander`s with trailing **Select All / Clear All** text actions, **Item Shop** only while the Shop is visible, and **Double Bass**.
  2. With a player only: **Global Score & FC Toggles** `Expander` (four web switches with descriptions, all visible charts at once), then **Individual Score & FC Toggles**: one `Expander` per visible chart with the web labels ("Missing Lead Scores" …).
  3. With a player only: **Selected Instrument Filters**: the shared Instrument Selector (`DeferSelection`; compact previous/next at the drawer width, like the web) revealing **Season**, **Percentile**, **Stars** and **Song Intensity** `Expander`s of bucket switches, each with trailing **Select All / Clear All** text actions (`HyperlinkButton`s) above the switches. Star rows draw the web star images, intensity rows the bar meter; both keep text names for UIA.
- Web `ToggleRow` template (`FilterToggleTemplate`): label or visual, optional description, trailing `ToggleSwitch` named by the label. Expanders start collapsed like web Accordions.
- Live semantics (operator 2026-09-28): opening loads the applied filters; every change applies at once; Reset clears and applies; no Cancel/Apply. Hidden-chart checks stay saved (InfoBar) until the next change applies without them.
- Model: `SongGeneralFilter(ExcludedDecades, ExcludedDurationBuckets, DoubleBassSupported, DoubleBassUnsupported)` persists General filters. Year options are catalogue decades; Duration offers 0–9 plus 10 only when present. Missing year/duration metadata is excluded only while that section is active. `SongShopFilter(available, unavailable)` replaces v2 `inShop` / `leavingTomorrow`; Shop availability is inert while the Shop is hidden. `SongFilter(Instrument, ExcludedIntensities)` and `SongPlayerScoreFilter` are player-scoped; while no player is selected they do not narrow the list or tint Filter.
- Player buckets: `SongFilter(Instrument, ExcludedIntensities)` (web `instrumentFilter` + `difficultyFilter` `false` keys `1–7, 0`); `SongPlayerScoreFilter` adds `ExcludedSeasons` / `ExcludedPercentiles` / `ExcludedStars` (web `seasonFilter` / `percentileFilter` / `starsFilter`, keys in `Domain/SongFilterBuckets.cs`). Buckets apply only with a visible instrument selected, after the score/FC checks; season/percentile/stars pause with the score filters (Filter Invalid Scores, mismatched index). Percentile bucket = first threshold ≥ rank / entries × 100; 0 = no score or no rank.
- Profile links (win-detail2's percentile rows and star cards): `SongsStatPreset` applies web `cleanFilters` (chart checks off, every bucket shown) then `Only(Percentile|Stars, key)` (web `buildPercentileFilter` / `buildStarFilter`).
- Persistence: settings **v3**. v1 files still migrate on load: a difficulty range on a chart becomes hidden intensity buckets outside it, and `songScoreBandFilter` becomes "show only that bucket" when it was on the selected chart. v2 `songShopFilter.inShop` or `leavingTomorrow` migrates to `available=true, unavailable=false`. Legacy keys are never written back. Unknown, duplicate, out-of-range or `null` decade/duration/intensity/player bucket lists are corrupt: Songs shows **Saved Filters Can't Be Read** until **Reset Filters**. Deselecting the player clears `SongFilter` and `PlayerScoreFilter`; General and Shop availability stay.
- IDs: `fst.songs.filter{,.form,.title,.reset}`, `fst.songs.filter.general`, `fst.songs.filter.year[.select-all|.clear-all|.<decade>]`, `fst.songs.filter.duration[.select-all|.clear-all|.<minute>]`, `fst.songs.filter.shop`, `fst.songs.filter.shop-available`, `fst.songs.filter.shop-unavailable`, `fst.songs.filter.double-bass`, `fst.songs.filter.double-bass.supported`, `fst.songs.filter.double-bass.unsupported`, `fst.songs.filter.score.global[.missing-scores|.has-scores|.missing-fcs|.has-fcs]`, `fst.songs.filter.score-sections`, `fst.songs.filter.score.chart.<chart>[.<check>]`, `fst.songs.filter.instrument-filters`, `fst.songs.filter.instrument.{<Solo_*>|compact|previous|next}`, `fst.songs.filter.<season|percentile|stars|intensity>[.select-all|.clear-all|.<key>]`, `fst.songs.score-filter-hidden`, `fst.songs.filter-invalid`, `fst.songs.filter-reset-invalid`.
- Journeys: `tools/windows/songs_journey.py` (`filter-web`, `songs-player`, `no-player` with a v1 settings file) and `tools/windows/songs_filter_journey.py` (issue #219: one scenario per reachable spec state, UIA-pattern steps only, so it runs on a locked console; Axe scan of each opened state). Scroll the form before reaching the selector (`scrollinto:id=fst.songs.filter.instrument.compact`). `tools/windows/songs_filter_fixture.py` wraps the mock service with `--shop demo|empty|error` and gives the demo songs `doubleBassSupported` (Pulse `true`, Orbit `false`; the shared fixture omits it, and `null` songs drop under either Double Bass option), so Double Bass narrowing is observable (issue #273). `anonymous-general` proves the no-profile General filters end to end: Double Bass, Year and Duration narrow live, Filter reads **Filters applied**, the choice survives a relaunch and still narrows after a player is selected.
- Applied marking: while any filter narrows the list, Filter's `AutomationProperties.ItemStatus` is **Filters applied** (`SongsViewModel.FilterStatus`; Narrator reads it after the name) and the label turns `FSTEmphasisBrush`. In a contrast theme the button fills `SystemColorHighlightColorBrush` with `SystemColorHighlightTextColorBrush` content and chevron (`winui-design` pairing table: Highlight + HighlightText for selected/emphasised content). Only while that pair is drawn the content children use `HighContrastAdjustment="None"`: WinUI's automatic text backplate otherwise draws Window-coloured boxes inside the Highlight fill (precedent: `LeaderboardEntryRow`).

## Validation (issue #219)

Fixture runs of `songs_filter_journey.py` (compact 500, medium 900, wide 1440 epx) and `a11y_matrix.py` (`songs-filter`, `songs-filter-applied`, `songs-filter-invalid`, Axe + Tab walk; keyboard `kb-songs-filter`, `kb-songs-sort-esc`); live-service screenshots for the resolution.

| Configuration | Result |
|---|---|
| Compact 500 epx, snapped half | Pass: flyout clamps to the window (flush to the edge, standard `Flyout` placement), Reset footer stays on screen; compact instrument selector |
| Medium 900 / wide 1440 epx, maximized | Pass: 440 epx drawer under the button, scrolls internally |
| Dark (app default) / Light system mode | Pass, identical: the app is Dark-only (`RequestedTheme="Dark"`, see [songs windows](../../pages/songs/windows.md)) |
| High contrast Night sky, Desert | Fixed: applied Filter now uses Highlight/HighlightText with no backplate boxes and a HighlightText chevron; flyout toggles/expanders use system colours |
| Text size 200% | Pass: rows wrap, toggles stay trailing, footer reachable by scrolling |
| Display scale 100% / 150% | Pass: epx layout unchanged |
| Keyboard only | Pass: Enter opens with focus on Year, Tab order Year → Duration → Item Shop → …, Space toggles, Esc returns focus to Filter (`kb-songs-filter`) |
| Narrator / UIA | Fixed: applied state was colour-only; now `ItemStatus` "Filters applied". Names/roles: Expanders (expand state), ToggleSwitches (toggle state, named by label), Reset button |
| Axe.Windows | 0 errors on `songs-filter`, `songs-filter-applied`, `songs-filter-invalid` in every mode/size (normal incl. maximized and snapped, light, Night sky, Desert, text 200%, scale 100%/150%), except: `songs-filter` medium at 150% scale reports `BoundingRectangleSizeReasonable` twice for the Karaoke expander's header text, clipped to zero height at the flyout ScrollViewer's top edge after `scrollinto` Percentile (WinUI viewport-edge clipping, [windows-accessibility](../../testing/windows-accessibility.md) item 3; scroll-position dependent, reproducible at that one size); and the journey's opened instrument selector popup reports WinUI's windowed `PopupHost` `BoundingRectangleCompletelyObscuresContainer` (item 8; filtered by name in the journey) |

Deliberate deviations from the `winui-design` skill (all web parity, see [spec](spec.md)): a light-dismiss `Flyout` drawer rather than a `ContentDialog` with Apply/Cancel (live apply); the full-width red Reset footer; `Expander` sections starting collapsed; Dark-only theme. A spoken Narrator pass needs an unlocked console; the UIA tree (names, roles, toggle/expand states, ItemStatus), Tab order and Axe stand in for it on this host.

States: `anonymous-hidden`, `player-loaded`, `player-unavailable`, `player-loading-shop-active`, `shop-draft`, `leaving-draft` (Leaving Tomorrow offers count as Available; no separate toggle), `reset-draft`, `applied`, `relaunch-persisted`, `shop-hidden-paused`, `shop-unavailable-paused`, `shop-validated-empty`, `shop-sort-badges-suppressed`, `deselected-paused`, `reselected-restored-native`, `normal-audit`, `score`, `full-combo`, `instrument`, `season`, `percentile`, `stars`, `intensity` are journey-covered; `largest-text` (text-200) and `focus-return` (`kb-songs-filter`, `kb-songs-sort-esc`) come from the matrix. Windows differences: live apply (operator 2026-09-28) has no Cancel/Apply draft, so `discard-confirm` is unreachable (the `anonymous` scenario asserts there is no Cancel/Apply); there is no band filter yet (`band-pending`, `band-member` unreachable); `shop-hidden-paused` keeps saved Shop availability inert with no notice, like the web; `publication-mismatch-paused` is unit-tested (`SongsShopTests`, `SongsListTests`) because the fixture cannot advance publications mid-session; after reselect, score filters stay cleared (deselect clears them) while General stays.
