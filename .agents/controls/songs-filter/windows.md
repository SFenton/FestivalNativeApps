# Songs Filter — Windows notes

> **What:** the Windows Filter flyout, its draft model and persistence. **Read when:** changing `SongFilterDraft`, the flyout in `SongsPage.xaml`, `SongFilter` / `SongPlayerScoreFilter` or the settings migration. Rules: [spec.md](spec.md).

- Light-dismiss `Flyout` sized like the web's 440 epx desktop drawer (clamped to the window; its height fits the space below the button so the red **Reset** footer stays on screen). Order follows the web `FilterModal` (operator 6.32 / 7.17; the old instrument ComboBox and difficulty sliders are gone):
  1. With a player: **Global Score & FC Toggles** `Expander` (four web switches with descriptions, all visible charts at once), then **Individual Score & FC Toggles**: one `Expander` per visible chart with the web labels ("Missing Lead Scores" …).
  2. **Item Shop** `Expander` (In the Shop / Leaving Tomorrow; disabled but kept and clearable while the Shop is hidden).
  3. **Selected Instrument Filters**: the shared Instrument Selector (`DeferSelection`; compact previous/next at the drawer width, like the web) revealing **Season**, **Percentile**, **Stars** (player only) and **Song Intensity** `Expander`s of bucket switches, each with trailing **Select All / Clear All** text actions (`HyperlinkButton`s) above the switches. Star rows draw the web star images, intensity rows the bar meter; both keep text names for UIA.
- Web `ToggleRow` template (`FilterToggleTemplate`): label or visual, optional description, trailing `ToggleSwitch` named by the label. Expanders start collapsed like web Accordions.
- Live semantics (operator 2026-09-28): opening loads the applied filters; every change applies at once; Reset clears and applies; no Cancel/Apply. Hidden-chart checks stay saved (InfoBar) until the next change applies without them.
- Model: `SongFilter(Instrument, ExcludedIntensities)` (public; web `instrumentFilter` + `difficultyFilter` `false` keys `1–7, 0`); `SongPlayerScoreFilter` adds `ExcludedSeasons` / `ExcludedPercentiles` / `ExcludedStars` (web `seasonFilter` / `percentileFilter` / `starsFilter`, keys in `Domain/SongFilterBuckets.cs`). Buckets apply only with a visible instrument selected, after the score/FC checks; season/percentile/stars pause with the score filters (no player, Filter Invalid Scores, mismatched index). Percentile bucket = first threshold ≥ rank / entries × 100; 0 = no score or no rank. Gold tint counts buckets only with an instrument (web `isFilterActive`).
- Profile links (win-detail2's percentile rows and star cards): `SongsStatPreset` applies web `cleanFilters` (chart checks off, every bucket shown) then `Only(Percentile|Stars, key)` (web `buildPercentileFilter` / `buildStarFilter`).
- Persistence: settings **v2**. v1 files migrate on load: a difficulty range on a chart becomes the hidden intensity buckets outside it (a range without a chart is dropped: intensity needs an instrument), and the v1 single percentile/star choice (`songScoreBandFilter`) becomes "show only that bucket" when it was on the selected chart. Legacy keys are never written back. Unknown, duplicate, out-of-range or `null` bucket lists are corrupt: Songs shows **Saved Filters Can't Be Read** until **Reset Filters**. Deselecting the player clears `PlayerScoreFilter` (buckets included); intensity and Shop choices stay.
- IDs: `fst.songs.filter{,.form,.title,.reset}`, `fst.songs.filter.score.global[.missing-scores|.has-scores|.missing-fcs|.has-fcs]`, `fst.songs.filter.score-sections` (heading), `fst.songs.filter.score.chart.<chart>[.<check>]`, `fst.songs.filter.shop`, `fst.songs.filter.{in-shop,leaving}`, `fst.songs.filter.instrument-filters` (heading), `fst.songs.filter.instrument.{<Solo_*>|compact|previous|next}`, `fst.songs.filter.<season|percentile|stars|intensity>[.select-all|.clear-all|.<key>]`, `fst.songs.score-filter-hidden`, `fst.songs.filter-invalid`, `fst.songs.filter-reset-invalid`.
- Journeys: `tools/windows/songs_journey.py` (`filter-web`, `songs-player`, `no-player` with a v1 settings file). Scroll the form before reaching the selector (`scroll:id=fst.songs.filter.score-sections,-40`).
