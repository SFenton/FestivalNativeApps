# Songs Sort — iPhone notes

> **What:** the SwiftUI Sort sheet as built and its layout lessons. **Read when:** changing Songs sorting on iPhone. Spec: [spec.md](spec.md).

- `SongCatalogSort` (Core) + `Features/Songs/SongsSortSheet.swift`: Title, Artist, Year, Duration, plus Item Shop only when Shop is visible (disabled until a validated feed loads). Changes apply as they are made (operator, 2026-09-28); the shared `FestivalModal`'s system Close dismisses (`fst.songs.sort.done` kept). Inline ↑/↓ direction control (`fst.songs.sort.direction.{ascending,descending}`); in-Form Reset.
- **Selected-player sorts (Lane A3):** with a selected player and one Songs instrument, a second section "Filtered Instrument Sort Mode" (`fst.songs.sort.player-mode`) offers **Score, Percentile, Stars** (web `INSTRUMENT_SORT_MODES` order; Percentage, Season, Intensity, Difficulty, Max Score %/Diff not ported), each hidden when Settings hides that row metadata (web `SortModal`). Ordering is the web's `compareByMode` (`SongScoreSortKey`): a song without a score sorts last ascending and first descending (web `cmp * dir`); Percentile is `rank / totalEntries`, unranked after ranked; ties by title. Rows are grouped into the web quick-link buckets (`SongCatalogSort.scoreSections`: "1.2M+"/"950k+" score floors, "5%" percentile buckets or "No Rank", "5★" star counts with spoken "5 stars"/"Gold stars") with Quick Links. The sort reads only a score index observed with the retained catalogue (`hasCurrentPlayerScores`); otherwise it pauses to Title with a visible reason (no player, Filter Invalid Scores on, publication mismatch). Without an instrument the saved mode resets to Title A–Z (web `normalizeSongSettings`), also on appear since the Songs instrument is not saved across launches.
- Sort sits in a `ToolbarItemGroup(.topBarTrailing)` alongside Filter (a `ToolbarSpacer` separates them from the profile button on iOS 26): bottom placement overlapped the Liquid Glass tab and activated Leaderboards. The toolbar button tints gold whenever the applied mode/direction isn't default Title A-Z.
- Title/Artist/Year sorting now drives a right-edge section-index "drag to jump" scrubber over the List ([songs-section-index/ios.md](../songs-section-index/ios.md)); it has no equivalent on web.
- Web differences: six radio rows with arrow hints and a red Reset vs native five inline choices; Has FC not ported; full-height system sheet vs web bottom sheet.
- Grouped Shop sections: zero vertical List insets on headers/links, 16pt horizontal gutters, so two selected cards clear the floating tab (`testSelectedShopSortSongsRowsClearFloatingTab`).
- Visual fixtures pin Title per launch via launch arguments without touching the saved preference.
- Tests: `SongCatalogSortTests`, `SongScoreBucketsTests` (player sorts and sections), device `testAnonymousSongsSortAppliesLiveAndSurvivesRelaunch`, `testAnonymousItemShopSortRestoresAfterHideAndFeedFailure`; web cases "anonymous Sort modal" / "anonymous Item Shop sort reorders Songs" in `tools/visual/pages.spec.ts`.
- Open: Has FC, Last Played and the other instrument modes, band modes, metadata priorities, landscape, largest type, grouped-screen full audit.
