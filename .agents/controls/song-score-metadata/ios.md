# Score metadata — iPhone notes

> **What:** the SwiftUI card policy/layout and its measured constraints. **Read when:** changing `SongProfileCardPolicy`, `SongMetadataFlow` or selected Songs rows. Spec: [spec.md](spec.md).

- `SongProfileCardPolicy` (`FestivalUI`) projects `PlayerScore`, catalogue `Song`/season and the eight saved switches into typed fields in source order; `SongMetadataFlow` wraps them right-aligned (`Features/Songs/SongProfileMetadataPills.swift`).
- Row order (issue #372): `SongProfileCardPolicy.reordered` applies `MetadataField.songRowOrder(independent:saved:)`: Settings' Song Row Visual Order while Enable Independent Song Row Visual Order is on, otherwise the web's `DEFAULT_METADATA_ORDER` (`MetadataField.defaultSongRowOrder`: Stars before Season Achieved). The first field becomes the right-aligned primary pill.
- When the effective order changes, UIKit reconfigures the retained Songs rows without replacing or resorting the list. Update the primary pill and the combined accessibility name together so the reading order follows what is visible ([HIG VoiceOver](https://developer.apple.com/design/human-interface-guidelines/voiceover)). Switching off restores the default display order without erasing the saved custom order.
- Place each wrapped pill at its **actual fitted width**: reserving the full width proposal left 14pt (iPhone) / 57pt (iPad) trailing gaps at AX5.
- Compare the Score's right edge with the **last** enabled pill (Last Played when present), within 2pt. At AX5, Last Played wraps with a shared leading text edge inside the pill; the pill itself aligns with the separate trailing Shop badge. Check the rendered text at these sizes ([HIG Typography](https://developer.apple.com/design/human-interface-guidelines/typography): test legibility in different contexts).
- Pills use scaled horizontal text insets: ≥4 painted glyph-to-edge pixels at xLarge, AX3 and AX5. At accessibility sizes stars become one star + a readable count. (The fixed Solo accuracy badge must **not** get padding — [score-accuracy](../score-accuracy/ios.md).)
- Full-combo accuracy and Top 1% use the shared skewed outline. The label scales without being sheared; the row still speaks the FC/percentile words once. Top 5% uses an upright gold outline. See [metadata pills](../../patterns/metadata-pills.md) and [HIG Accessibility](https://developer.apple.com/design/human-interface-guidelines/accessibility) (convey state with a shape as well as color).
- Hosted AX5 `ImageRenderer` passed with broken UIKit geometry once — keep device assertions and read real screenshots.
- Edge fixture: pinned port 8776 `--metadata-edge` (long title, 1,234,567 score, Shop New) — [fixtures](../../testing/fixtures.md).
- Open: Last Played sort, the sort's editable Metadata Priority (the order rows use with Independent Visual Order off), band cards, representative-catalogue performance.
