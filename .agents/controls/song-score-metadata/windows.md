# Selected-player score metadata — Windows notes

> **What:** Windows metadata pills on Songs rows (icons off or one chart filtered). **Read when:** changing `SongMetadataPolicy` or `SongRowVisuals.Pill`. Rules: [spec.md](spec.md).

- Fields and order: web `DEFAULT_METADATA_ORDER` unless Settings' **Enable Visual Order** is on, then `SongRowVisualOrder`. Each field honors its Settings toggle; an FC with Percentage hidden still shows `FC`.
- Last Played follows the web (issue #647, `SongsPage.visibleMetadataOrder` and `SongRow.displayOrder`). It shows only under the **Last Played** sort, whatever its Settings toggle says, as the row's **first** value. The pill is the date alone in the web's medium form (`SongMetadataPolicy.LastPlayedDate`, for example "Sep 28, 2026" in en-US or "28 Sept 2026" in en-GB; an unparseable value shows as sent), and it speaks "Last played <date>". With no chart filter, `SongRowProjector` adds the song's most recent play across Settings-visible charts (`SongMetadataPolicy.LatestPlay`, the same value the sort orders by): that chart's icon plus the date, spoken "Last played <date> on <chart>". It sits after the inline status chips, top-right when the chips wrap, and with icons off it leads the first visible chart's pills. Under every other sort, rows have no Last Played pill. The toggle stays in Settings for web parity, where it only filters the sort's metadata list.
- Pills: Score (bold), accuracy (red→green tint at 25% alpha; FC = gold outline `98.5% FC`), percentile and season from the shared `Controls/MetadataPills` (pattern [metadata-pills](../../patterns/metadata-pills.md), issue #606: Top 1% skewed gold outline, Top 5% gold outline, else neutral; season `textSecondary` on `surfaceSubtle`, inverted when current), stars (gold when 6), Intensity (`DifficultyMeter`), game difficulty (E/M/H/X on the difficulty pill brushes, dark text on Easy/Hard), Last Played date (secondary 12 pt, after a 20-epx raw-view chart icon when unfiltered).
- Placement is one page-wide decision (`SongMetadataLayout`, web `resolveCompactRowMode`): every row puts all its pills inline beside the title when the list column fits the widest value of every enabled field (pills measured detached at the current text size and contrast, plus 114 epx row chrome and a 180-epx title), otherwise the first pill stays top-right and the rest wrap right-aligned under the title. A 32-epx hysteresis stops a resize on the threshold from flapping. The decision re-runs on list resize, text-scale change, Settings toggles and a contrast switch. With all fields on at 100% text under the Last Played sort the threshold is a ~864-epx list, so pills sit inline in windows about 1,200–1,420 epx wide (page below the 1,100-epx split-view breakpoint). Under every other sort the Last Played sample isn't measured (#647), so the threshold is lower and the 900-epx `medium` preset is inline too. Compact and snapped halves wrap, and so does split view (list fixed at 560 epx), which a maximized or `wide`-preset window reaches on a 100% or 150% display.
- A non-Lead chart shows its icon before its own first pill and is spoken there ("Bass chart"). The unfiltered Last Played entry names its own chart instead. Zero score = `No score`.
- Test IDs: `fst.songs.metadata.<field>.<songId>` (`score`, `percentage`, `percentile`, `stars`, `season`, `intensity`, `difficulty`, `lastplayed`), `fst.songs.metadata.chart.<songId>` for the chart icon and `fst.songs.metadata.state.<songId>` for `No score`, `Loading scores`, `Scores syncing` and `Scores unavailable`.
- Accessibility: each pill is a `MetadataPill` (one raw-view UIA element with the spoken name; its peer hides the inner text, so nothing is read twice; Image for stars and intensity, Text otherwise). Narrator reads the pills once, through the row's ListViewItem name. Pills have a 22-epx minimum height (season and percentile 24 epx, `MetadataPillStyle`) and grow with text size, so 200% text never clips them. Difficulty letters keep dark text on the Easy/Hard brushes by design (web parity).

## Validation (issue #228, 2026-10-04)

Fixture: `tools/windows/song_metadata_fixture.py` (designed player `fixture-meta` on the mock service, plus a slow twin and the large catalogue). Journeys: `tools/windows/journeys/song-score-metadata.json` via `a11y_matrix.py --scan`, asserting each state by UIA name and placement (`assertlevel:`/`assertbelow:`). Run `metadata-large-text` (the `medium` window) only with `--mode text-200` (`--only metadata-large-text`): at 100% text that window is inline under the Title sort by design (#647), so its `assertbelow:` fails, and the 100%-text placement pages (`metadata-inline`, `-wrapped`, `-resize`) likewise fail at 200%. Last Played (#647): `tools/windows/journeys/a11y-songs-last-played.json` (`ui_ci` runs `a11y-songs-last-played-normal` and `-text-225`) checks that the Title sort shows none even with the toggle on, that the Last Played sort leads with "Last played Sep 28, 2026 on Lead" (unfiltered, icon plus date) or the bare date (Lead filter), and its inline, wrapped and chips placement. The dates assume an en-US host. Result on 2026-10-14: every page passed with 0 Axe errors, plus the full `song-score-metadata.json` set.

States covered: anonymous, loading, syncing, failed, no score, score primary, score hidden (accuracy primary), FC and FC-only, graded and missing accuracy, Top 1% (gold fill), Top 3% (top-five gold outline) and ordinary percentile, five gold stars and star counts, current and old season, intensity, game difficulty, Bass chart named, filtered chart, invalid saved filter paused then reset, Shop row. Band-blocked does not apply on Windows: Songs never shows band metadata.

Design review (`winui-design`, `winui-code-review`):
- Fluent responsive layout says to reflow content at breakpoints and to size text containers so they never clip when text scales. The pills therefore use a minimum height and a measured, page-wide reflow, not fixed heights or a fixed width.
- Pills are display-only, so they are not focusable and have no Tab stop. Narrator reads them once, through the row's name.
- Deliberate deviations, kept for web parity: the pills' fixed font sizes (they follow the system text scale), dark letters on the Easy and Hard difficulty brushes, and icon-sized stars and intensity meters at large text.
