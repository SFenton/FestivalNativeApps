# Installed PWA vs native app: Apple gaps

> **What:** visible differences between the installed PWA and our native app, captured the same day on the same device and orientation, with a suggested fix and owner. **Read when:** picking UX-parity work; before changing a page that appears here. Measurements and clips: [apple.md](apple.md).

Device: iPhone 17 Pro, 26.5, portrait unless noted (2026-09-28). PWA media: `~/FestivalShowcase/pwa/ios/`; native: `~/FestivalShowcase/pwa/native-ios/` (same file names). Native clips came from `ios_sim.py drive --record` (Debug build, background frozen unless `--animate`), so compare shape and motion type, not absolute load time. **P1** means a visible layout or control difference; **P2** is animation or polish. "Keep, native" marks a deliberate Apple HIG deviation.
